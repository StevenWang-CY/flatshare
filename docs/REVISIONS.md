# Revisions

Flatshare's history was rewritten on 2026-10-27. Its 740 commits became 100, each one change titled by its area,
and host and account names were taken out of every file in it. Each release tag, v0.1 to v1.3, is on a commit
with exactly the files it had, those names aside.

The records name the revision each measurement ran on as `git describe` of the earlier history (for example
`v0.3-191-g987fd09`), and a few logs and documents name an earlier commit by its hash. This table gives each the
first commit of this history that holds it. Where the table says *same files*, that commit has exactly the files
the earlier revision had; otherwise it holds the same change among the others it was combined with, or, for a
commit of a branch rebased before it merged, the change as it reached main.
